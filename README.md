## Stack du site

Next.js 16 (App Router, pages statiques) · React 19 · TypeScript · Tailwind CSS v4 · Framer Motion · déployé sur Vercel.

Toutes les données affichées (parcours, projets, compétences) sont centralisées dans [`lib/data.ts`](lib/data.ts).

## Lancer en local

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # build de production
```
